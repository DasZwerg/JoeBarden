v3.2.3

Summary: Groq AI fallback, security hardening, critical startup fix.

🤖 AI - GROQ FALLBACK
- Added Groq (Llama/Mixtral) as a fallback when Gemini fails entirely.
- Gemini is tried first. Groq only activates on full Gemini failure.
- Groq models in order: llama-3.3-70b, llama-3.1-8b, mixtral-8x7b.
- Set GROQ_API_KEY in .env to enable. Free key at console.groq.com.

🔧 CRITICAL FIX
- Bot startup was broken - bot.run(token) was missing. Now fixed.

🔒 SECURITY
- $roastdj now sanitizes display names before passing to AI prompt.
- Removed unknown dependency from requirements.txt (typosquat risk).

🎛 IMPROVEMENTS
- Gemini model selection replaced with a probed preferred-model list.
- Model order: gemini-2.5-flash, 1.5-flash, 1.5-pro, 2.0-flash.
- Replaced discord.Intents.all() with a minimal explicit intent set.

v3.0

Summary: Critical playback fixes, loop rework, effect state cleanup.

🔧 CRITICAL FIXES
- Fixed songs enqueuing but never playing after 3 min idle timeout.
- Fixed Already Playing errors from stale voice client state.
- Fixed ffmpeg log spam from redundant manual process tracking.

- $loop now requires on|off argument ($loop on / $loop off).

v2.3

Summary: New commands, playlist persistence, richer playback controls.

🎵 NEW COMMANDS
- $nightcore on|off  - nightcore playback effect.
- $replay           - restart current track.
- $history          - recently played tracks.
- $playlist save|load|list - per-server playlist persistence.
- $votemode on|off  - vote-based skip mode.
- $mood happy|chill|rage|focus - mood-based song presets.
- $roastdj          - roast the DJ or a tagged user.
- $stats            - uptime and playback metrics.
- $nowbar           - live track progress bar.

🔧 FIXES
- Fixed .env load order for MUSIC_CHANNEL_ID parsing.
- Fixed patchnotes path when bot launched from a different directory.
